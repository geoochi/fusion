# 2026-07-11

## OPML export backend API

- Added backend OPML export endpoint `GET /api/opml/export` (auth-protected).
  - New file `backend/internal/handler/opml.go`: `exportOPML` handler + `buildOPML` helper.
  - Uses `encoding/xml` structs for safe attribute escaping; produces OPML 2.0 with feeds nested under their group (mirrors frontend `generateOPML`). Feeds whose group was deleted are emitted at top level.
  - Returns `text/x-opml` with `Content-Disposition: attachment; filename="fusion-subscriptions.opml"`.
  - Route registered in `backend/internal/handler/handler.go` under the `auth` group.
- Wired frontend to the new backend endpoint instead of client-side OPML generation:
  - Added `opmlAPI.export()` in `frontend/src/lib/api/index.ts` (fetches blob, triggers download).
  - `handleExport` in `frontend/src/routes/feeds.lazy.tsx` now calls `opmlAPI.export()`; removed now-unused `generateOPML`/`downloadFile` imports and unused `feedAPI`/`groupAPI` value imports.
- Validation (per CONTRIBUTING.md): backend `goimports`/`go test ./...`/`go build` pass; frontend `tsr generate` + `tsc -b --noEmit` + `pnpm lint` + `pnpm build` pass.
- Note: store `ListGroups`/`ListFeeds` return `[]*model.Group` / `[]*model.Feed` (pointers, not values).
- Note: `goimports` is not preinstalled in this env; installed via `go install golang.org/x/tools/cmd/goimports@latest` (binary at `$(go env GOPATH)/bin/goimports`).
- Note: frontend `tsc -b --noEmit` requires `npx tsr generate` first to produce `src/routeTree.gen.ts`, otherwise 23 cascade errors about `never`/`undefined` route types appear (pre-existing, unrelated to changes).
